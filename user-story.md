# User Stories - GiftLink Capstone Project

## Overview
This document outlines the user stories developed using Agile methodology for the GiftLink full-stack web application.

---

### User Stories

1. **User Registration & Authentication**
   * **As a** new user,
   * **I want to** register an account with a unique email and secure password,
   * **So that** I can access personalized features and manage item listings.

2. **User Login**
   * **As a** registered user,
   * **I want to** log in securely using JSON Web Tokens (JWT),
   * **So that** my session is authenticated across the application.

3. **Browse & View Gift Listings**
   * **As a** user looking for items,
   * **I want to** view a list of available household items with descriptions and images,
   * **So that** I can find things I need for free or to recycle.

4. **Detailed Item View**
   * **As a** user interested in a specific item,
   * **I want to** click on an item to view its detailed page, full description, condition, and comments,
   * **So that** I can decide whether to request it.

5. **Search & Filter by Category**
   * **As a** user searching for specific items,
   * **I want to** filter items by category or search by keywords using natural language support,
   * **So that** I can quickly locate relevant listings.

6. **Add New Gift Item**
   * **As a** donor,
   * **I want to** list a household item I no longer need with photos and category details,
   * **So that** others can claim or recycle it.

7. **User Profile Management**
   * **As a** registered user,
   * **I want to** view and update my profile information,
   * **So that** my account details stay current.

8. **Comments and Reviews**
   * **As a** community member,
   * **I want to** leave comments or reviews on item listings,
   * **So that** I can communicate with the donor or ask questions.
